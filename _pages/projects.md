## 1. AI assistant for space missions (2026)

I transformed thousands of mission documents and sparse notes into an instantly searchable knowledge base for an enterprise RAG system. I designed the architecture and developed an end-to-end pipeline to ingest, parse, structure and enrich heterogeneous corporate documents, making their content retrievable by LLMs, including information contained in tables and images. The resulting system turned previously fragmented knowledge - often accessible only through manual searches or senior engineers' expertise — into an AI-powered resource for anomaly investigation, procedure discovery and technical decision-making.

<span>*</span> This software is proprietary and cannot be shared or made available to external users.

## 2. Real-time Geospatial Intelligence (2026)

I developed a web application around an internal real-time SAR processing pipeline for ML-based vessel detection and classification. The application orchestrates pipeline execution and provides a live view of SAR imagery, detections and their metadata as they are generated, showcasing the detection algorithm's real-time performance. Its scalable architecture supports new areas and inputs, turning a high-performance internal capability into an accessible tool for showcasing and exploiting the team's work.

<span>*</span> This software is proprietary and cannot be shared or made available to external users.

## 10. VarSum (2021) 

[<img src="images/varsum-uc.png" alt="Example analysis with VarSum" width="800px">](https://github.com/DEIB-GECO/VarSum/blob/master/demo/UC%20B%20-%20Differential%20variant%20analysis%20to%20unveil%20cancer%20genes/UC%20B%20-%20Differential%20variant%20analysis%20to%20unveil%20cancer%20genes.ipynb)

A RESTful API enabling user-personalized queries to a multi-source repository of genomic variants and annotations. 

[Example of Use and Analysis (Jupyter Notebook)](https://github.com/DEIB-GECO/VarSum/blob/master/demo/UC%20B%20-%20Differential%20variant%20analysis%20to%20unveil%20cancer%20genes/UC%20B%20-%20Differential%20variant%20analysis%20to%20unveil%20cancer%20genes.ipynb) [GitHub](https://github.com/DEIB-GECO/VarSum) [API docs](https://geco.deib.polimi.it/popstudy/api/ui/)

The presented data is the result of a two-stage pipeline:
1. the GMQL pipelien building the Genomic Data Repository
2. an extensible ETL pipeline processing data from 1KGenomes, TCGA and GENCODE to generate the relational data model used by VarSum.
